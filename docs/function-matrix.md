## Acceptance boundary

The current candidate is suitable for public source review, not a claim of production readiness. A clean `npm test` and `npm run scan` show only the candidate's isolated code and history passed those checks. Live OAuth, real Windows DPAPI/ACL under the adopter account, host approval UI, Gmail send/receipt, production API permissions, deployment monitoring, actual task registration, and scheduled production execution remain unverified.
